学校で共同編集を使う

学校ごとに、自分たち専用の共同編集の場を用意します。手順書を生成 AI に貼ると、1ステップずつ案内してくれます。

しくみ

学校ごとに、次の3つを用意して共同編集の場を作ります。

用意するもの 役目
Supabase（無料プラン） ログインと、書いた内容の保存
Vercel（無料プラン） アプリを公開する場所
学校の Google Apps Script（使うときだけ） 生徒が学校のアカウントで入るときの本人確認。先生かどうかの見分け

ログインのしかた

入り方
先生 Google アカウントでログイン。または学校のアカウント（先生として登録した人）
生徒 先生が開いた「部屋」の6文字の合言葉と、表示名で入る。または学校のアカウント
  • 生徒は、メールアドレスも、学校の外のアプリへの Google ログインもいりません
  • 部屋は24時間で自動で閉じます。先生は、部屋に入った生徒を外せます
  • 学校のアカウントで入った生徒は、どの Chromebook からでも同じ人として続きが書けます。先生には、その学校の生徒が作ったマンダラが全部見えます

手順

手順書は、生成 AI に貼って使う形にしてあります。AI が、画面の操作を1つずつ案内します。

  1. 配布用のリポジトリ（mandala-app-template）の 導入手順.md を開く
  2. 右上の コピー（Copy raw file）を押して、全部をコピーする
  3. 生成 AI（Claude・ChatGPT・Gemini など）に貼り、「この手順で、1ステップずつ案内してください」と書いて送る
# すること 使うサービス
1 アプリのプログラムを、自分の GitHub に写す GitHub
2〜4 データベースを作り、ログインを設定する Supabase・Google Cloud
5〜7 アプリを公開して、先生として使ってみる Vercel
8 学校の GAS を置く（止まらないしくみ・学校のアカウントで入る） 学校の Google アカウント
9〜10 学校のアカウントで入るボタンを出す（使うときだけ） Supabase・Vercel
11〜12 プライバシーポリシーを直し、生徒で試す GitHub・アプリ
  • AI には、パスワードやキーなどの秘密の値を貼らないでください。手順書にも、AI が貼らせないように書いてあります
  • 困ったときは、マンダラ発想法のページの「要望・不具合のフォーム」からお知らせください

気をつけること

  • 学校で使うときは、学校や設置者のきまりに沿って、使ってよいかを確かめてください
  • Supabase の無料プランは、1週間使われないと止まるきまりがあります。この点は対策済みです：学校の Google Apps Script が毎日1回（朝4時ごろ）自動で Supabase を呼ぶので、長い休みのあいだも止まりません。動いたかどうかは、Apps Script の設定画面で毎日の記録を見て確かめられます

サービスの画面や料金は変わることがあります（2026年11月23日 に確かめた内容です）。
