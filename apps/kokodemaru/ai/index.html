AI 読み取りを使う（Gemini・Claude API）

理科用語や説明問題の読み取りと採点を、AI に手伝わせます。おすすめは Claude API です。使わなくても採点はできます。

おすすめは Claude API

Claude API をおすすめする理由は、次の5つです。

  1. 取り違えが起きない：解答欄を1つずつ送るので、番号と画像の取り違えが起きません。Gemini は PDF をまとめて渡すため、取り違えることがあります（ココデマルは、確認用の欄で見つけて、その部分の読み取りを使わないようにしています）
  2. 手間がかからない：PDF の保存・ドラッグ・指示文の貼り付け・答えの貼り戻しが要りません。自動で読み取ります
  3. できることが多い：スキャンした正答例の正答も、自動で読めます
  4. 答案の PDF がチャットの履歴に残らない：Gemini では、渡したファイルが Gemini 側に残り、ココデマルからは消せません
  5. 費用の上限を決められる：ココデマルの中と、Claude Console の両方で決められます

Gemini を選ぶとき：費用をかけられないとき、Claude API を使う許可が出ないときは、Gemini を使ってください。

2つの方法

Gemini Claude API（おすすめ）
しくみ 読み取り用の PDF を、学校のアカウントの Gemini に手で渡し、答えを貼り戻す 解答欄を自動で送って読み取る
費用 追加の費用はかかりません（学校や自治体が契約している Google のサービスの範囲） 使った分が、API キーの持ち主に請求されます。1か月の上限を決められます
必要なもの 学校のアカウントで Gemini が使えること Claude Console のアカウントと API キー
向いている人 費用をかけられない人、Claude API の許可が出ない人 正確に、手間なく読み取りたい人

学習に使われないことを、必ず確かめる

2026年11月8日に確かめた扱い 確かめること
Gemini Google Workspace の契約の対象になっている学校のアカウントでは、渡したファイルやチャットは、人による確認に回されず、モデルの学習にも使われないとされています 自分のアカウントが契約の対象か、会話の履歴が残る期間（学校の管理者に聞く）。個人の Google アカウントの Gemini には、答案を渡さない
Claude API 初期設定では、送った内容はモデルの学習に使われません Console で、データを学習に提供する設定をオンにしていないこと。答案の画像が入った内容を、フィードバックや不具合の報告として送らないこと

⚠ サービスの決まりは、予告なく変わります。 上の表は、2026年11月8日に各社の説明で確かめた内容です。使い始める前と、年度の初めなどに、必ず各サービスの最新の説明と、自分のアカウントの設定を確かめてください。

手順のあらまし

  1. ココデマルの右上の「⚙ 初期設定」で、「AI 読み取り（理科用語・説明問題の自動採点）」にチェックを入れる
  2. 「AI 読み取りの方法」で、Gemini か Claude API を選ぶ
  3. Claude API のときは、API キーを作って貼り付け、「接続を確かめる」
  4. 画面の上に出る「AI読み取り」のタブから使う

くわしい手順は、ココデマルの手引きの 3. 初期設定（AI 読み取り） を見てください。

気をつけること

  • AI の読み取りや採点の候補は、必ず先生が確かめてから使ってください
  • API キーは、その端末のブラウザの中だけに保存されます。共用のパソコンでは使わず、使い終わったら「APIキーを消す」を押してください
  • 正答例や問題用紙を AI に読ませるときは、テストの発行元のきまりも確かめてください

サービスの画面や料金は変わることがあります（2026年11月8日 に確かめた内容です）。
