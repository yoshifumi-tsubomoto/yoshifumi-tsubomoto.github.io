しくみ：プログラムと答案の動き

配る場所 GitHub アプリのプログラムを置いているだけ
プログラムだけが届く
先生のパソコン ブラウザ（Chrome・Edge） ココデマルが動く
答案・名簿・採点結果を、ここに保存
答案・結果は送らない
外 作者・ほかの先生・サーバー 答案も結果も届かない

プログラム

  • URL を開くと、GitHub からアプリのプログラムだけが届き、先生のブラウザの中で動きます。ログインはいりません
  • 一度開くと、プログラムはブラウザにしまわれます。次からはネットがなくても開けます
  • 新しい版が出ると、画面に知らせが出ます。更新するかどうかは、先生が選べます（勝手には変わりません）
  • プログラムを受け取るとき、GitHub には、ふつうのホームページを見たときと同じアクセスの記録が残ります。答案や結果は含まれません

答案・名簿・採点結果

  • 開いている端末のブラウザの中だけに保存します。作者を含め、だれのサーバーにも送りません
  • 何人が同時に使っても、それぞれのブラウザに別々に保存されるので、おたがいのデータは見えません
  • アクセス解析など、使い方を外に知らせる仕組みも入っていません
  • 外に送るのは、先生が「AI 読み取り」を有効にしたときだけです（名前の欄を白く消した解答欄の切り抜き。AI 読み取りを使う を見てください）

自分で確かめる方法：一度ココデマルを開いたあと、Wi-Fi を切ってからもう一度開いてみてください。ネットにつながっていなくても、そのまま採点できます。サーバーがなくても動く、ということです。

手順

  1. Chrome か Edge で、ココデマル を開きます
  2. アプリとして登録します（おすすめ）。アドレスバーの右の端にあるボタン（ブラウザでは「アプリをインストール」と表示されます）を押すと、スタートメニューやデスクトップ（Chromebook ではシェルフ）にアイコンができ、専用の窓で開けるようになります。パソコンにソフトを入れるわけではありません
    • ブラウザに採点データを消されにくくなります（ブラウザは、空き容量が少ないときなどに、サイトのデータを消すことがあります）
    • 登録しなくても使えますが、そのときは、こまめにバックアップを書き出してください
  3. 一度開けば、ネットがなくても開けます

自分の答案がなくても試せます

ダミーのデータで試す方法 を見てください。

気をつけること

  • データは端末ごとに別です。学校の PC の続きを家の PC でするときは、「データと情報管理」からバックアップを書き出して、もう一方で読み込みます
  • 同じテストを2つのタブで同時に直さないよう、タブは1つで使ってください
  • 学校で使うときは、学校の情報管理のきまりに従ってください
