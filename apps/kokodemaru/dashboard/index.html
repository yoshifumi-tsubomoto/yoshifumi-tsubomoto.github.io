生徒ダッシュボードを Google ドライブに置く

採点した結果と答案の画像を、生徒が自分の学校のアカウントで見られるようにします。

補足
置き場所は、先生自身の学校のアカウントのドライブです。生徒は、自分の学校のアカウントで自分の分だけを見られます。ほかの生徒の分や、先生のフォルダは見えません。
学校の情報管理のきまりで使えるかを確かめてから使ってください。

答案の画像と結果は、先生の学校のアカウントの Google ドライブに入ります。ドライブのフォルダは、だれとも共有しないでください。

はじめに（1回だけ）

  1. テンプレート を、学校のアカウントで開きます
  2. 左の ⓘ（概要）→ 右上の「コピーを作成」
  3. コピーで「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」
    • 次のユーザーとして実行：自分
    • アクセスできるユーザー：（学校のドメイン）内の全員（「全員」にはしないでください）
  4. 「デプロイ」→ 許可を求められたら、内容を確かめて許可します
  5. 出てきた URL（…/exec）を開くと、先生用の画面が出ます

テストごとに

  1. 採点アプリの「⑤ 出力」→「ダッシュボード用の ZIP を保存」
  2. 先生用の画面で、その ZIP を選ぶ
  3. 先生用の画面の「生徒に伝える URL」を、Classroom などで生徒に知らせる
  4. 見せる期間が終わったら、そのテストの「公開をやめる」を押す

くわしくは 手引きのダッシュボードの準備 を見てください。

サービスの画面や料金は変わることがあります（2026年11月8日 に確かめた内容です）。
