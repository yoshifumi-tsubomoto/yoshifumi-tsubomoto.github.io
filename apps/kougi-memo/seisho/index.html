清書と要約を使う（OpenAI・Gemini）

セッションのあとで、録音をていねいに文字にし直し（清書）、要約も自動で作ります。自分の API キーを使います。

しくみ

リアルタイムの文字起こしは、速さを優先するので誤りが出ます。セッションが終わったら、録音を OpenAI か Gemini に送り、ていねいに文字にし直します（清書）。清書した文字から、要約も自動で作れます。

  • 送るのは、「✨ 清書する」「✨ 要約を作る」を押したセッションの分だけです。押す前に、送ってよいかを確認します
  • API キーは、あなたの端末のブラウザの中にだけ保存します。作者には届きません
  • 清書が済んだ録音は、消して場所をあけられます

2つの方法

OpenAI Gemini
清書のしかた 文字起こし専用の AI（whisper-1 など）。細かい時刻が付く 音声を読ませて、時刻付きで書き起こさせる
費用（1時間） 約50〜60円（whisper-1）、約25〜30円（gpt-4o-mini-transcribe） 約15〜25円（2.5 Flash）
必要なもの OpenAI のアカウントと API キー（支払いの設定） Google AI Studio の API キー（支払いの設定をした有料の枠）

費用は 2026年11月16日の各社の料金をもとにしためやすです。料金は変わることがあります。実際に使った額は、各サービスの管理画面で確かめてください。

手順のあらまし

  1. OpenAI（platform.openai.com）か Google AI Studio（aistudio.google.com）で、API キーを作ります。支払いの設定もします
  2. 講義メモの「⚙ 設定」→「清書（高精度の文字起こし）の方法」で、OpenAI か Gemini を選びます
  3. 出てきた欄に、API キーを貼り付けます
  4. セッションを終了したら、「まとめ・出力」の「✨ 清書する」を押します
  5. 清書が終わったら、「✨ 要約を作る」を押します

くわしい手順は、講義メモの手引きの 8. 清書する を見てください。

気をつけること

  • 清書や要約は AI が作るものです。大事なところは、録音やメモと見比べて確かめてください
  • 共用のパソコンには、API キーを入れないでください
  • サービスの決まりは、予告なく変わります。 使い始める前と、ときどき、各サービスのデータの扱いと料金を確かめてください

サービスの画面や料金は変わることがあります（2026年11月16日 に確かめた内容です）。
