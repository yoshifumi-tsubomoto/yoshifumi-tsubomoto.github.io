プログラム

  • URL を開くと、GitHub からアプリのプログラムだけが届き、あなたのブラウザの中で動きます。ログインはいりません
  • 一度開くと、プログラムはブラウザにしまわれます。次からはネットがなくても開けます（リアルタイムの文字起こしには、ネットが必要です）
  • 新しい版が出ると、右上の版の番号が「新しい版あり」に変わります。更新するかどうかは、あなたが選べます。記録中に勝手に変わることはありません

記録（文字起こし・メモ・写真・録音）

  • 開いた端末のブラウザの中だけに保存します。クラウドには保存しません
  • 何人が同時に使っても、それぞれのブラウザに別々に保存されるので、おたがいの記録は見えません
  • 外に送るのは、リアルタイムの文字起こしのための話している音声だけです。Chrome（Edge）の音声認識のしくみで、Google（Microsoft）に送られます

手順

  1. Chrome か Edge で、講義メモ を開きます
  2. 「＋ 新しい講義」を押し、タイトルを入れます
  3. 講義が始まったら「● セッション開始」を押します。マイクの使用を聞かれたら「許可」します
  4. アプリとして登録すると、さらに使いやすくなります（おすすめ）。右上の「⬇ アプリにする」を押すと、専用の窓で開けるようになります。パソコンにソフトを入れるわけではありません
    • ブラウザに記録を消されにくくなります（ブラウザは、空き容量が少ないときなどに、サイトのデータを消すことがあります）
    • 登録しなくても使えますが、そのときは、こまめに書き出してください

気をつけること

  • 講義を録音・文字起こしするときは、講師や主催者の了解を得てください
  • 記録は端末ごとに別です。終わったら「まとめ・出力」から、フォルダやバックアップに書き出してください。バックアップは、別の端末で読み込めます
  • マイクは、話す人の声が直接届く位置にあるほど、文字起こしが正確になります
  • 長い講義のときは、パソコンを電源につなぎ、スリープしない設定にしてください
  • 学校や職場で使うときは、そこの情報管理のきまりに従ってください
